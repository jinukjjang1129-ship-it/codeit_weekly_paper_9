# [Weekly Paper] 지도 학습 vs 비지도 학습 및 손실 함수의 역할

## 1. 지도 학습(Supervised Learning) vs 비지도 학습(Unsupervised Learning)

머신러닝은 데이터의 형태와 학습 목적에 따라 크게 두 가지 방식으로 나뉩니다.

### 지도 학습 (Supervised Learning)
- **정의**: 문제(Feature)와 정답(Label)이 함께 주어진 데이터를 학습하는 방식입니다.
- **특징**: 모델은 입력값과 정답 사이의 관계를 파악하여, 새로운 데이터가 들어왔을 때 정답을 예측하는 것을 목표로 합니다.
- **주요 작업**:
  - **회귀(Regression)**: 연속적인 숫자 값을 예측 (예: 집값 예측, 주가 예측)
  - **분류(Classification)**: 범주형 데이터를 예측 (예: 스팸 메일 여부, 개/고양이 분류)

### 비지도 학습 (Unsupervised Learning)
- **정의**: 정답(Label) 없이 문제(Feature)만 있는 데이터에서 숨겨진 패턴이나 구조를 찾아내는 방식입니다.
- **특징**: 데이터 간의 유사성을 측정하거나 차원을 축소하여 데이터의 본질적인 특징을 요약하는 데 집중합니다.
- **주요 작업**:
  - **군집화(Clustering)**: 비슷한 데이터끼리 그룹화 (예: 고객 세그먼트 분류)
  - **차원 축소(Dimensionality Reduction)**: 데이터의 핵심 특징만 추출 (예: PCA)

## 2. 손실 함수(Loss Function)의 정의와 중요성

### 손실 함수란?
모델의 예측값($\hat{y}$)과 실제 정답($y$) 사이의 차이를 수치화하는 함수입니다. 모델이 얼마나 "틀렸는지"를 나타내는 지표라고 볼 수 있습니다.

### 주요 종류
- **MSE (Mean Squared Error)**: 회귀 분석에서 주로 사용하며, 오차의 제곱합 평균을 계산합니다.
- **Cross-Entropy**: 분류 문제에서 모델이 예측한 확률 분포와 실제 분포의 차이를 계산할 때 사용합니다.

### 손실 함수가 중요한 이유 (Why it matters?)
1. **학습의 나침반 역할**: 모델은 이 손실 함수의 값을 최소화하는 방향으로 가중치(Weight)를 업데이트합니다. 즉, 학습이 잘 되고 있는지 판단하는 유일한 기준입니다.
2. **최적화(Optimization)의 근거**: 경사 하강법(Gradient Descent)과 같은 최적화 알고리즘은 손실 함수의 기울기를 이용해 파라미터를 조정합니다. 손실 함수가 없다면 모델은 어느 방향으로 수정되어야 할지 알 수 없습니다.
3. **모델 성능의 정량화**: 모델의 복잡도나 하이퍼파라미터 변경이 실제 예측 오차를 얼마나 줄였는지 객관적인 수치로 증명해 줍니다.

> **결론**: 지도 학습은 정답을 맞히는 학습이고, 비지도 학습은 데이터의 특징을 스스로 파악하는 학습입니다. 이 과정에서 모델이 정답에 가까워지도록 가이드하는 핵심 장치가 바로 손실 함수입니다.
